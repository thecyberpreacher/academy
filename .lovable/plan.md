# CyberPreacher Academy Website Plan

## Goal
Build a polished single-page landing site for CyberPreacher Academy that communicates credibility, drives inquiries, and works on all devices.

## Brand Direction
- **Theme:** Geometric / cyborg-inspired cybersecurity academy
- **Colors:** Black, gold, white as requested
- **Mood:** Premium, technical, authoritative, future-forward
- **Logo:** Placeholder area reserved; user will provide asset later

## Sections (single page, scrollable)

1. **Navigation**
   - Sticky top nav with logo placeholder, links to sections, WhatsApp CTA
   - Mobile hamburger menu

2. **Hero**
   - Headline: "Build Elite Cybersecurity & AI Security Experts"
   - Subheadline about expert-led, weekend-only virtual training
   - Two CTAs: "Enroll via WhatsApp" and "Email Us"
   - Geometric/circuit-like decorative background elements in gold on black

3. **About**
   - Founded 2024 by Steven Osonuga (CISSP, CEH), co-founded by Praise Awowoyin
   - Mission statement: "Setting the global standard for cybersecurity excellence."
   - Stats: 4 expert-led programs, virtual, weekend format

4. **Training Programs**
   - 4 cards:
     - Cybersecurity Fundamentals — 4 weeks, 8 hrs/week
     - Ethical Hacking & Penetration Testing — 12 weeks, 8 hrs/week
     - Digital Forensics — 8 weeks, 8 hrs/week
     - AI Security — 4 weeks, advanced
   - Each card: duration, format, brief description, CTA

5. **Why Choose Us**
   - Expert instructors, hands-on labs, weekend schedule, virtual delivery
   - Icon + short text grid

6. **Founders**
   - Steven Osonuga (Founder) and Praise Awowoyin (Co-Founder)
   - Photo placeholders, brief bios if provided; otherwise names + roles

7. **Contact / Final CTA**
   - WhatsApp button (primary)
   - Email button (secondary)
   - Simple contact details placeholder

8. **Footer**
   - Copyright, social links placeholder, quick links

## Functionality
- Pure frontend landing page; no backend required
- WhatsApp link with pre-filled message
- mailto: link for email inquiries
- Smooth scroll to sections
- Responsive layout (mobile, tablet, desktop)

## SEO / Metadata
- Title: "CyberPreacher Academy | Cybersecurity & AI Security Training"
- Description under 160 chars
- OG tags, Twitter card, canonical tag
- Alt text on images

## Technical Notes
- TanStack Start single route at `/`
- Tailwind CSS v4 with custom black/gold/white tokens in `src/styles.css`
- Lucide icons for UI elements
- Placeholder image/avatar areas until user provides assets

## Out of Scope
- User accounts / enrollment database
- Payment processing
- Blog or multi-page navigation
- Custom domain setup (will note steps for user to connect later)
